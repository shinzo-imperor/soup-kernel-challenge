Soup Kernel Challenge
Decentrathon 6.0
This repository contains our solution for the Soup Kernel Challenge.
Project structure
The solution/ directory contains the implementation of the custom kernels:
• entropy.py — entropy computation.
• nf4.py — NF4 operations.
• rmsnorm.py — RMSNorm implementation.
• swiglu.py — SwiGLU implementation.
• test_kernels.py — kernel tests.
• __init__.py — Python package initialization.
Technologies
• Python
• PyTorch
• Triton
• GPU kernel optimization
